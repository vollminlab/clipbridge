# clipbridge

> One keystroke on a Windows laptop puts a screenshot in front of Claude Code on a remote box.

Take a screenshot on the laptop, press `Ctrl+Shift+V`, and the image is written to
`devsbx01` and its path typed straight into the tmux pane you were last working in — no
`scp`, no file juggling.

**Status: design approved, not yet implemented.**
